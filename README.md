# Resume Website

A simple personal resume website created while learning **HTML and CSS**.

## 🌐 Live Website

**[View My Resume Website](https://kamchor-exe.github.io/Resume/)**

## 📌 About the Project

This project is a basic online resume designed to present my:

* Personal information
* Education
* Skills
* Projects
* Experience
* Contact details

The main goal of this project was to practice the fundamentals of **HTML and CSS** and understand how a simple website is structured and styled.

## 🛠️ Technologies Used

* HTML5
* CSS3
